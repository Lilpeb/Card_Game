# Contributions

Copy this file into your **group** repository as `CONTRIBUTIONS.md`, then update it
**before every checkpoint** (Weeks 4, 8, 12). It is how your team proves that each member
personally contributed each required topic.

**How to fill it in:** in each cell, put a **commit hash** (e.g. `a1b2c3d`) - or, if your
team is using them, a **merged pull request** (e.g. `#14`) - authored by that student that
demonstrates that topic in their slice. One cell can reuse the same PR/commit if it genuinely covers two
topics (e.g. a function that also holds the feature's state). A **blank cell** means that
student did not demonstrate that topic for that milestone.

Keep all three sections in this one file - do not delete the earlier milestones; the
history matters.
